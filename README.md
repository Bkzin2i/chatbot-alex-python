# ChatBot Alex — Python

Um chatbot desenvolvido em Python que conversa com o usuário e armazena algumas informações utilizando um arquivo JSON.

## Funcionalidades

- Respostas para mensagens simples.
- Identificação e armazenamento do nome do usuário.
- Armazenamento da cor favorita.
- Armazenamento do jogo favorito.
- Memória persistente entre execuções.

## Tecnologias utilizadas

- Python
- JSON

## Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra um terminal na pasta do projeto.
4. Execute:

   ```bash
   python alex.py
   ```

   No Windows, se necessário, utilize `py alex.py`.

## Objetivo

Projeto de estudo para praticar funções, dicionários, estruturas condicionais, manipulação de arquivos e persistência de dados em Python.
